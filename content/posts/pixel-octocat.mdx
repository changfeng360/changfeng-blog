# 把一只 GitHub 像素猫放进网站角落

用 SVG 的矩形像素一点点拼出敲代码的小猫，顺手给它加上了眨眼和打字动画。

## 像素猫的拼法

先用网格纸画出轮廓，再把每一格转成 SVG 矩形。颜色少一点，像素感反而更明显。

## 小动画

眨眼用 scaleY，打字用宽度变化，频率保持一致就不会显得突兀。

## 放对位置

像素猫适合待在角落和卡片边缘，作为彩蛋出现，而不是抢占主要内容。
