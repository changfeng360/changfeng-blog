# Agent 工作流里最容易被忽略的一环

让 Agent 真正可靠，往往不是给它更多工具，而是把反馈回路、上下文卫生和失败恢复做扎实。

## 反馈回路

每一步执行之后都需要把可观察的结果带回去，Agent 才能判断下一步该怎么做。

## 上下文卫生

不必要的历史记录会稀释注意力。及时压缩、归档和清理，比堆更多上下文更有效。

## 失败恢复

把失败变成一次可重试的步骤，而不是让整个流程停摆。
